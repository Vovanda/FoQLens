# FoQLens

Стенд направленного квантования: точность весов распределяется по смыслу запроса, экспертные зоны проявляются, а не задаются роутером. Постановка и план - в `docs/`, прогнозы - в `prereg/`.

## Дисциплина стенда (не нарушать)

- **Предрегистрация неприкосновенна.** `prereg/PREREGISTRATION.md` после коммита не правится. Уточнение - новым файлом и новым коммитом с датой, старое остаётся.
- **Порядок коммитов:** предрегистрация → код прогонов → запуск → результаты отдельными коммитами.
- **Слепой анализ.** Все прогоны разом, по ходу смотреть только что скрипт не упал. Исключение - шаг 0.
- **Отложенные темы** (`prompts/heldout/`) не открываются и не прогоняются при отладке скора.
- **Два baseline** на шаге 3: равномерное квантование и случайная маска той же концентрации.

## Стек

- Gemma 4 E2B (отладка) / E4B (подтверждение), base-чекпойнты `google/gemma-4-E2B`, `google/gemma-4-E4B`. MoE 26B-A4B не брать.
- transformers + bitsandbytes, lm-evaluation-harness. Не ollama / llama.cpp / LM Studio - прячут активации и не дают менять точность поблочно.
- Окружение - `uv` в `.venv`, Python 3.12. Глобальный Python не использовать.
- Железо: RTX 3090 Ti 24 ГБ.
