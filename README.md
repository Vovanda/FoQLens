# FoQLens

Стенд направленного квантования. Точность весов распределяется по смыслу запроса: грубый проход первых слоёв определяет, о чём речь, по этому считается, какие блоки читать точно, остальные грубо. Экспертные зоны не выделяются заранее, а проявляются. Роутера нет.

Имя: Focus + Quantization + Lens. Lens - графическая метафора, не механика.

## Главная цель

Показать, что точность, распределённая по весам под смысл запроса, даёт лучшее качество при том же среднем числе бит, чем равномерное квантование и чем случайная маска той же концентрации.

## Порядок работы

Предрегистрация → код прогонов → запуск → результаты. Каждое - отдельным коммитом, история показывает, что предсказания были раньше данных.
