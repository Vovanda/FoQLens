The documents of the bench

FoQLens is a language model whose weights are read at a precision set by the meaning of the query; its mechanism is FoQZones, focusable quantization zones. This is the documentation of the bench that tests it - the mechanism, the goals, the plan and every preregistration.

Pick a document on the left. Each is a markdown file in the repository, and every link below goes to its source.
