# Data sources - run 1

Which questions the bench is fed, why this source was chosen, and what was rejected. Decided 2026-09-11, before any run. This is the source of **run 1**; later runs may use another benchmark - each run records its own sources in a file like this one.

All numbers below were read from the Hugging Face API on 2026-09-11, not quoted from memory.

## Requirements

What the source has to give:

1. Every preregistered domain: biology, math, chemistry, physics, biophysics (debugging); history, geography (held-out).
2. One question format across all domains - otherwise topic separation can latch onto format, source or length instead of the topic.
3. Correct answer keys - step 3 measures quality, and label noise goes straight into that number.
4. A pinned, public version, so independent researchers get the same questions.

## Tier list

| Tier | Source | Reasoning |
| --- | --- | --- |
| **S** | **MMLU-Redux-2.0**, `error_type == "ok"` only, + own biophysics | MMLU re-annotated by hand: 100 questions per subject, each labelled with `error_type`; in high-school biology 95 of 100 are `ok`. All required subjects exist, the format is the same everywhere, answer keys are cleaned, so step 3 can measure quality on the same questions. No biophysics subject exists anywhere, so that set is written by hand regardless of the source. |
| **A** | **MMLU** (original) | Same subjects, more questions (151-310 per high-school subject), but its keys are noisier - exactly what Redux removes. Separation (steps 0-1) barely cares; step 3 accuracy does. |
| **B** | **MMLU-Pro** | More questions (biology 717, physics 1299) and 10 options, but: no geography, which is a held-out domain; its STEM questions were added from other sources (STEM Website, TheoremQA, SciBench) while history comes only from the original MMLU, so separation could learn the source instead of the topic; and it may be close to the floor for a 2B model, leaving step 3 nothing to measure (assumed, not checked). |
| **C** | **Own questions, hand-written** | Full control, biophysics included, but slow, needs its own answer keys for step 3, and every question carries its author's style. Fine as an addition, not as the main source. |
| **C-** | **Questions generated by Claude** | Fast, but one uniform style can blur or inflate separation - and the author would be a party to the step 1 bet. |
| **D** | **SciQ** | 13.7k science questions, but no subject field: biology, chemistry and physics would have to be labelled by hand; no math, history or geography. |

Separate role: **PAWS** (`google-research-datasets/paws`, `labeled_final`) for scale calibration - labelled paraphrase pairs.

## Choice for run 1

**Tier S.** MMLU-Redux-2.0 at revision `372ea425445d51e1ba1188c56e5e893f8138621f`, split `test`, rows with `error_type == "ok"`, question text only (no options, no chat template).

### Why history is `prehistory`

The three MMLU history subjects are built on quoted sources: the median question length is 1215 characters in `high_school_world_history`, 1201 in `high_school_us_history`, 1360 in `high_school_european_history` - against 78-201 for every other domain. Topic separation on such data would measure input length. `prehistory` is the one short history subject (median 85 characters, 100 of 100 `ok`).

Caveat: prehistory partly overlaps with biology (human evolution). The preregistered predictions are not changed because of this; it is recorded so the confirmatory step 2 result is read with it in mind.

### Biophysics

No dataset has a biophysics subject, so 30 questions are written by hand for run 1: factual, school-to-early-university level, each needing both biology and physics. Their author is Claude, a party to the step 1 bet. The mitigation: they are committed before any run, written without seeing a single mask.

### Calibration

From PAWS `labeled_final` at revision `161ece9501cf0a11f3e48bd356eaa82de46d6a09`, split `test`:

- **paraphrases** - pairs with `label == 1`;
- **unrelated** - sentences from different pairs, paired at random with a fixed seed. PAWS negatives (`label == 0`) are not used: they are word-order scrambles with almost the same words, not unrelated texts.
