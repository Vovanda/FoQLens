# Визуальная метафора

Фильтр квантования работает как многолинзовое стекло с зонами разного фокуса: через него мы смотрим на сеть
и берём из неё знание, а линзы подбираются под запрос. Через матовую линзу детали теряются, зато видна
структура вещей; через прозрачную всё видно в подробностях.

За метафорой механизм распределяет точность весов по смыслу запроса
([precision-regulator.ru.md](precision-regulator.ru.md)). Саму метафору можно покрутить руками на главной
странице сайта проекта.

Имя проекта, FoQLens, идёт отсюда: на слух автора линза звучит мягче, чем зоны.
