# E004 - Адрес вопроса: преррегистрация

Записана 2026-09-19, до прогонов.

## 1. Зачем

Регулятор решает раскладку по вопросу, значит ему нужен адрес - число на блок, по которому один вопрос отличается от другого. Адрес должен сниматься дёшево (иначе экономии не будет) и держаться за смысл вопроса, а не за его формулировку: иначе перефраз даст другую раскладку, и механизм окажется ловушкой на слова.

## 2. Устройство

- **Модель и база**: gemma-4-E2B-it поверх bartowski Q2_K, адрес читается на базовой точности D2.
- **Корпус**: замороженный малый корпус, TriviaQA / NQ / SQuAD; перефразы к 60 вопросам TriviaQA пишу я, имена собственные сохраняю.
- **Источники**: активность нейронов на входе down_proj, энергия голов внимания, их объединение, градиент.
- **Мера**: узнавание - доля вопросов, чей ближайший адрес остаётся собственным при смене обёртки (0-shot против 2-shot) и при перефразе.
- **Контроль**: мешок токенов вопроса. Источник, который узнаёт перефраз не чаще мешка токенов, держится за слова.
- **Дешёвое чтение**: гребневая проекция первых N слоёв на адрес остальной сети, обученная на калибровке.

## 3. Предсказания

- **P1.** Есть источник, узнающий свой вопрос при смене обёртки чаще порога 0.5. Опровергается, если все ниже.
- **P2.** Есть источник, узнающий перефраз чаще мешка токенов. Опровергается, если ни один не превосходит контроль.
- **P3.** Первые слои на базовой точности дают тот же адрес, что полный проход: косинус со своим адресом заметно выше, чем с чужими.
- **P4.** По самому вопросу видно, нужно ли читать глубже - то есть глубину можно выбирать адаптивно. Опровергается, если площадь под кривой около 0.5.

## 4. Критерий

Все меры считаются на одних и тех же вопросах. Малая выборка называется числом вопросов рядом с результатом.

## 5. Прогон

Маски источников считаются один раз и кладутся на диск (`runs/masks/`), проверки читают их оттуда; вывод - `runs/address/`.
