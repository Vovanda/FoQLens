# E004 - The address of a query

What to read a query with to get its address in the network: which signals identify the query rather than its wording,
and whether the address can be taken cheaply - from the first layers at base precision instead of a full pass. This is
the left half of the mechanism: without an address the regulator has nothing to tell one query from another.
