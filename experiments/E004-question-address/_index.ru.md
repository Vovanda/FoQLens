# E004 - Адрес вопроса

Чем читать вопрос, чтобы получить его адрес в сети: какие сигналы узнают свой вопрос, а не его формулировку, и можно ли снять адрес дёшево - по первым слоям на базовой точности вместо полного прохода. Это левая часть механизма: без адреса регулятору нечем отличать один вопрос от другого. Преррегистрация: [PREREG](PREREG.ru.md), результаты: [results](results.ru.md).
