# E004 - Адрес вопроса: результаты

Прогоны 19.09.2026. Конфигурация итоговых чисел: gemma-4-E2B-it поверх bartowski Q2_K, малый корпус, TriviaQA / NQ / SQuAD, гребневая проекция с коэффициентом 0.1.

## Источники адреса

Узнавание - доля вопросов, чей ближайший адрес в другой обёртке остаётся собственным; перефразы писал я, имена собственные сохранены, контроль - мешок токенов вопроса.

| источник | через обёртку | перефраз | годен |
|---|---|---|---|
| активность нейронов | 0.995-1.000 | 0.892 | да |
| энергия голов внимания | 0.964-0.993 | 0.692 | слабее |
| объединение их обоих (`pooled`) | 0.820-0.886 | 0.308 | нет, держится за формулировку |
| градиент | 0.473-0.490 | - | нет |

Случайный уровень 0.003-0.02, мешок токенов 0.717.

Активность нейронов несёт смысл сверх слов: узнаёт перефраз чаще, чем их общие токены (0.892 против 0.717). Энергия голов работает на уровне слов, `pooled` - ниже слов.

## Гибрид

Гибрид активности и энергии голов, каждая часть нормирована на свою длину, обе читаются за один проход:

| проверка | гибрид | активность | голова |
|---|---|---|---|
| через обёртку | 0.997-1.000 | 0.995-1.000 | 0.964-0.993 |
| перефраз | **0.917** | 0.892 | 0.692 |
| глубокий адрес, N = 6-8 | 0.877-0.893 | 0.816-0.855 | 0.357-0.629 |

Гибрид - лучший адрес из проверенных. По геометрии он почти совпадает с активностью (согласие 0.96), головы добавляют 2-8 пунктов на глубоком адресе.

## Дешёвое чтение

Первые 12 слоёв на базовой точности дают тот же адрес, что полный проход на bf16: косинус со своим адресом 0.97 у активности, 0.87-0.93 у голов, с чужими около нуля.

Гребневая проекция первых N слоёв предсказывает адрес остальной сети: при N = 4-8 узнавание 0.82-0.89, и под зонами остаётся 84-92% весов. Чтение окном слоёв вместо всех первых N выигрыша не дало. Рабочая точка - гибрид, N = 6.

## Глубина чтения по вопросу не выбирается

Сложные вопросы не читаются глубже простых: площадь под кривой сдвига 0.44, и даже оракульный отрыв, который берёт настоящий глубокий адрес, даёт 0.53-0.70. Правило силуэта - читать, пока верхние блоки адреса не устоятся два слоя подряд - по узнаванию не лучше фиксированной глубины той же средней цены.

Пробы на тридцати тривиальных вопросах и двадцати пяти сложных: средняя остановка 6.70 против 6.48, то есть сложные останавливаются даже раньше.

## Что это значит для механизма

Адрес вопроса снимается дёшево и узнаёт смысл, а не формулировку - левая часть регулятора есть. Чего адрес не даёт: глубину чтения выбрать по нему нельзя, а предсказать по нему карту точности не удалось - в E005 мост из адреса по ответам не отличим от постоянной карты.
