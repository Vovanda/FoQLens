# Рецепт проверки H0, H1 и H2: что набрать из корпуса

E006 на эти три гипотезы не отвечает, и причина одна: его выборка набрана по трудности вопроса, а не по теме.
Сто вопросов взяты как 50 трудных и 50 обычных из пяти корпусов, темы в них не размечены, пар вопросов к
одному отрывку нет ни одной.

Здесь записано, что именно надо набрать, чтобы проверка стала возможна, - чтобы не собирать это заново из
памяти через месяц.

---

## Что проверяет каждая из трёх

**H0 - разделяются ли темы в представлениях модели.** Проверка пригодности: если вопросы одной темы дают более
похожие поля, чем вопросы разных, тема в представлениях есть. Если нет - слаба модель, и всё, что стоит на
темах, отпадает.

**H1 - поблочные маски разделимы по темам и сконцентрированы.** Половина уже измерена в E006: концентрация
есть, карта поднимает 13-40% секций, пики узкие. Разделимость по темам не измерена.

**H2 - зоны родственных тем перекрываются больше, чем неродственных.** Нужны пары тем с известным родством:
биология и химия против биологии и математики.

## Чего не хватает в нынешней выборке

| нужно | есть в E006 |
| --- | --- |
| пары вопросов к одному отрывку | ни одной |
| тема, размеченная у каждого вопроса | нет разметки |
| пары родственных и неродственных тем | нет |
| вопросы одной темы из разных источников | случайно и без пометки |

Корпус в E006 играет роль формата, а не темы: SQuAD читает отрывок, ARC отвечает на школьный вопрос,
TriviaQA и NQ спрашивают факт. Совпадение полей внутри корпуса 0.09-0.13 - ровно столько же, сколько между
корпусами, и это говорит про формат.

## Что набрать

Три набора, каждый со своим контролем. Числа - минимум, при котором разница в 0.1 по мере похожести отличима
от разброса; они взяты по тому, как вели себя меры в E006, где разброс по парам был 0.05-0.08.

**Набор А, подтема (для H0).** 20 отрывков SQuAD v2, к каждому 3 вопроса из корпуса - 60 вопросов. Пары внутри
отрывка: 60 пар. Контроль: пары вопросов к разным отрывкам того же корпуса, столько же.

Данные это позволяют: в SQuAD v2 11 873 вопроса на 1204 отрывка, и все 1204 несут три и более вопроса, 1190
из них - пять и более. Отрывки группируются по своему тексту: номера отрывка в корпусе нет, `corpora.Row`
несёт `context`. Проверить состав:

    uv run python -c "from foqlens import corpora; from collections import Counter; rows, _ = corpora.read('squad_v2'); c = Counter(r.context for r in rows if r.context); print(len(c), sum(1 for v in c.values() if v >= 3))"

**Набор Б, тема (для H0 и H1).** Четыре темы из школьных корпусов ARC, где тема стоит в самом вопросе:
биология, химия, физика, науки о Земле. По 15 вопросов на тему - 60 вопросов. Пары внутри темы против пар
между темами.

Разметка берётся из готовых файлов `prompts/biology.jsonl`, `prompts/chemistry.jsonl`, `prompts/physics.jsonl`
- они уже разложены по доменам, - либо размечается вручную по тексту вопроса; ручная разметка в этом случае
честнее, потому что домен файла и тема вопроса совпадают не всегда.

**Набор В, родство (для H2).** Те же четыре темы, но пары считаются по заданному родству: биология-химия и
физика-науки о Земле как родственные, биология-математика и химия-литература как неродственные. Под
неродственные нужна пятая тема, далёкая от естественных наук: 15 вопросов по истории или литературе.

Итого 135 вопросов сверх нынешних 150.

## Как мерить

На каждом вопросе снимается поле оракула, из него вычитается костяк сети - иначе сравнение поймает общий фон,
как это уже случилось с согласием оракулов (0.61 до вычета и 0.17 после).

Дальше три меры, те же, что в E006 (`foqlens.maps`): доля групп с одинаковой ступенью, Жаккар по поднятым
группам, расхождение в битах. Плюс корреляция вопросных частей полей, медиана по парам.

**Критерий для H0 и H1.** Пары внутри темы похожи заметно сильнее, чем пары между темами, по всем трём мерам
сразу. Опорные числа из E006: случайная пара даёт 0.09-0.13, перефраз того же вопроса - 0.51-0.97. Тема
должна лечь между ними, ближе к перефразу.

**Критерий для H2.** Перекрытие зон у родственных пар больше, чем у неродственных, на величину больше разброса
внутри группы.

**Контроль, без которого числа ничего не значат.** Те же меры на парах, подобранных по совпадению слов, а не
по теме. Если совпадение слов объясняет всё, темы в картах нет, а есть лексика. В E006 похожие по словам
вопросы давали совпадение формы 9-15%.

## Во что обойдётся

Оракул на 135 вопросах - около полутора часов по времени E006 (сто вопросов за 432 секунды на групповом
оракуле плюс поля, которые идут дольше). Ответы модели для этой проверки не нужны: меряются поля и карты, а
не удержание ответа.

Перефразы к этим вопросам не нужны - они отвечают на другой вопрос, про слова.
