# E006: прогоны

Выборка: 100 вопросов - 50 трудных, где отвечает только верхняя ступень, и 50 обычных того же состава по
корпусам, - плюс 50 перефразов. Заморожена в `sample/` до первого прогона.

Что где лежит:

| папка | что это | зачем |
| --- | --- | --- |
| `sample` | списки вопросов и их тексты | что меряли; `search.json` - десятка, на которой искалась полоса |
| `masks` | маски по блокам: энергии ступеней, градиент | сырьё для полей; в git не идут, велики |
| `answers` | ответы на своих картах, 22 раскладки | основной замер |
| `paraphrased` | оракул, маски и поля на перефразах | тот же вопрос другими словами |
| `carried` | ответы на карте своего перефраза | H1.1 |
| `carried-other` | ответы на карте соседа по цене | H3.1 |
| `elsewhere` | ответы на своей фигуре, сдвинутой по сети | H3.4 |
| `random` | ответы на случайно розданных ступенях | H3.3 |
| `bands` | ответы на сетке допусков, десять вопросов | поиск полосы |
| `maps` | блок всех карт и сетевая часть полей | пересобирается `scripts/build_maps.py` |

Инвариант всех контролей: память совпадает до байта - 0.6098 у своей карты против 0.6099 у перенесённой.
Без этого сравнение ничего не значит.

Что из этого следует, коротко:

- Карта держит ответ там, где ровная ступень той же и большей памяти не держит: на трудных 0.80 против 0.14 у
  ровной D6.
- Карта принадлежит вопросу, а не бюджету и не форме: чужая карта 0.59, своя фигура в другом месте 0.61,
  случайная раздача 0.62 - против 0.86 у своей.
- Вырожденные карты считаются отдельно: у `lift` 34 карты из ста - это вся сеть наверху, и они завышали замер.
  Без них 0.79 вместо 0.86, на трудных 0.69 вместо 0.80.
- Полоса не подбирается: границы `1 / (1 + r)` по измеренным отношениям ошибок ступеней, k = 1. Поиск на
  десяти вопросах это подтвердил, а не выбрал.

Разбор полей - `experiments/E006-filter-map-retention/fields.ru.md`, полосы - `bands.ru.md`.

## Что лежит архивами

В репозитории остаётся то, по чему считался разбор: сводки каждой раскладки, поля, блоки карт, оракул по
группам, замороженная выборка и README каждой серии. Сами ответы и сырьё упакованы рядом - распаковывать в эту
же папку.

| архив | что внутри | размер |
| --- | --- | --- |
| `answers-e006.zip` | ответы всех серий: свои карты, сотня, перефразы, четыре контроля, три сетки | 2.8 МБ |
| `grids-e006.zip` | сводки и логи трёх сеток поиска шкалы, 197 точек | 0.5 МБ |
| `masks-e006.zip` | маски по блокам, сырьё всех полей: 14 файлов, 1.7 ГБ развёрнутыми | 60 МБ |

Те же три архива лежат в релизе репозитория `e006-artifacts`.

Серия `bands` - первый поиск полосы по одной ручке k - удалена: её числа тем же счётом не воспроизводятся, и
разбор на них не опирается.

Маски пересчитываются из модели, если архив не нужен: `scripts/small_corpus_masks.py` и
`scripts/gradient_oracle.py`, около семи минут на сотню вопросов.
