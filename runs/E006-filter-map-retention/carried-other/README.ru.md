# Ответ на карте другого вопроса

Контроль H3.1. Вопросы разбиты на пары по цене их карт, ближайшие друг к другу, и каждый отвечает на карте
соседа. Память при этом та же.

Инвариант: пара подбирается по цене, поэтому сравнение идёт при равной памяти, а не «как вышло».

Главное: 0.59 против 0.86 у своей карты при цене 0.625 у обеих. Карта принадлежит вопросу, а не бюджету.
