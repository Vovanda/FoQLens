# Своя фигура, сдвинутая по сети

Контроль H3.4. Ступени карты переставлены внутри классов групп равного веса: фигура та же, место другое, память
совпадает до байта.

Инвариант: ступень переезжает только на группу с тем же числом весов - 0.6098 против 0.6099.

Главное: 0.61 против 0.86. Решает не то, сколько и каких ступеней роздано, а каким блокам.
