# Маски по блокам

Энергия ошибки ступеней D2, D4, D6 и градиентный оракул на тех же вопросах, отдельно на исходных текстах и на
перефразах. Это сырьё: поля собираются из них, сами они в git не идут - каждый файл десятки мегабайт.

Инвариант: маска снимается тем же текстом, каким оракул читал вопрос. Маску перефраза нельзя класть под поле
исходного вопроса.

Пересчитываются: `scripts/small_corpus_masks.py --source <источник>`, градиент - `scripts/gradient_oracle.py`.
