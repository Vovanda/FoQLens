# Перефразы

Те же вопросы, пересказанные синонимами и другим порядком слов, с теми же именами и числами. Через весь путь:
оракул перебора, маски энергии, градиент и поля - всё прочитано на перефразе, а не на исходном тексте.

Инвариант: перефраз держит id исходного вопроса, поэтому его карта встречается с картой вопроса по этому id.

Главное: поле перефраза совпадает с полем вопроса на 0.61-0.63 у полей вопроса и на 0.92-0.99 у полей сети;
после вычета общей части сети перефраз узнают все оракулы, 0.51-0.96, а чужой вопрос падает к нулю.
