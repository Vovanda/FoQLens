# Ступени, розданные наугад

Контроль H3.3. Те же ступени того же вопроса, разложенные случайно внутри классов равного веса.

Инвариант: память не меняется, меняется только адрес каждой ступени.

Главное: 0.62 против 0.86. Вместе с двумя другими контролями - все три способа испортить карту дают около 0.60,
значит 0.86 держится выбором блоков.
