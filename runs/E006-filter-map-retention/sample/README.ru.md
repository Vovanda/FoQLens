# Выборка E006

Сто вопросов и пятьдесят перефразов, заморожены до первого прогона.

- `hard.json`, `ordinary.json` - по 50 пар «корпус, id»; состав по корпусам одинаковый, обычные взяты в долях трудных
- `*-questions.jsonl` - тексты тех же вопросов, чтобы не поднимать корпус ради чтения
- `hard-paraphrased.json`, `ordinary-paraphrased.json` - по 25, к которым написан перефраз
- `all.json` - сто вместе, `paraphrased.json` - пятьдесят перефразированных
- `search.json` - 5 трудных и 5 обычных, на которых искалась полоса; на остальных 90 она проверяется

Инвариант: списки не меняются после первого прогона. Вопрос попадает в трудные, если верхняя ступень отвечает,
а D4 и D6 обе нет; в обычные - если отвечают все три.
