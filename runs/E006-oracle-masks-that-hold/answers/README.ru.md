# Ответы на своих картах

22 раскладки на сотне вопросов: четыре ровные ступени и карты каждого оракула, построенные поиском порога по
ответу. Генерация идёт рядом с тем же вопросом при всей сети наверху, в тех же батчах, - иначе ответы несравнимы.

Инвариант: сравнение идёт с ответом верхней ступени на том же вопросе, не с золотым ответом.

Главное: карта держит 0.86 ответов верхней ступени при 0.61 её памяти; на трудных 0.80 против 0.14 у ровной D6,
которая дороже. Без вырожденных карт - 0.79 и 0.69.
