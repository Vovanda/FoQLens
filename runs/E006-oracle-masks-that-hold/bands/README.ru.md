# Поиск полосы

Десять вопросов - 5 трудных и 5 обычных, `sample/search.json` - на сетке допусков k = 0.5, 1, 2, 4, 8. Полоса
читает поле спроса по границам 1 / (1 + r / k), где r - доля ошибки базы, которую оставляет ступень.

Инвариант: поиск идёт только на этих десяти; остальные 90 при подборе не открывались.

Главное: оптимум у всех оракулов k = 1, то есть границы, выведенные из лестницы без подбора. При k = 2 ответы
рушатся у всех, а цена падает на 3-5 процентов - размен плохой. Лучший на этой полосе - `drop`: 5 трудных из 5
при цене 0.524.
