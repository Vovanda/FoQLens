# Блок карт

Всё, что у вопроса есть: каждое поле каждого оракула и карта, которую оно даёт на каждом допуске. Вопросы и
группы перечислены один раз, карта зовётся `<оракул>@k<допуск>`.

- `maps-*.npz` - `demand` [поля, вопросы, группы] и `levels` [поля, допуски, вопросы, группы]
- `network-part-*.npz` - общая часть каждого поля: среднее по всем вопросам

Пересобирается одной командой:

    uv run python scripts/build_maps.py --fields <файл полей> --out runs/E006-oracle-masks-that-hold/maps

Инвариант: `levels[o, j]` получается из `demand[o]` границами `1 / (1 + ratios / ks[j])` - это проверяет тест,
а не обещание.

Главное: поле оракула - общая часть сети плюс добавка вопроса. У `lift` и `drop` сеть объясняет 9-18 процентов
поля, у энергии ошибки и градиента 73-83. Согласие оракулов держалось на общей части: энергия с `pooled` 0.61 до
вычета и 0.17 после.
